# Xinrou Zhang portfolio

Ready for GitHub Pages. The public site has no editing tools or browser-local content storage. The desk fills the viewport; project and About pages scroll normally.

## Publish at https://XinrouZ.github.io/

1. Create a public repository named `XinrouZ.github.io` under the XinrouZ account.
2. Upload everything in this folder to the repository root, including `assets`, `.github`, and `.nojekyll`.
3. In Settings → Pages, choose **GitHub Actions** as the source.
4. The included workflow deploys after a push to `main`. Its Actions run provides the live URL.

No build or installation is required. For a different repository name, this site also works at the repository's GitHub Pages address because asset paths are relative.

## Future changes

Text and image references are in the `portfolio-content` block in `index.html`; styles are in `style.css`; interactions are in `script.js`. A separate editable draft is retained outside this public package.
